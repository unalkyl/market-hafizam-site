# Market Hafızam — Privacy & Support site

Static privacy-policy and support pages for the **Market Hafızam** mobile app,
hosted free on GitHub Pages. No backend, no tracking — these pages mirror the
app's actual (zero-collection) data behaviour.

- `privacy.html` — Gizlilik Politikası (privacy policy; the URL submitted to both stores)
- `support.html` — Destek / SSS (support + FAQ)
- `index.html` — landing page
- `style.css` — shared styling

## Hosting

GitHub → **Settings → Pages → Deploy from branch `main`, folder `/ (root)`**.

Live URLs:
- Privacy: `https://unalkyl.github.io/market-hafizam-site/privacy.html`
- Support: `https://unalkyl.github.io/market-hafizam-site/support.html`
